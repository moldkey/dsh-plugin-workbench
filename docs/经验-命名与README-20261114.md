# 插件命名与 README 经验（2026-11-14）

## 命名
- 借需求词，不自创：sheetmetal / dwg / pdf / invoice 这类用户已经在搜的词
- 品牌词（AutoCAD/SolidWorks）只进 keywords 和 description，**不进包名**，避免商标风险
- 一个词根一个包：dsh-sheetmetal、dsh-hs-code；套装另起 dsh-manufacturing
- scope 包（@scope/name）在部分搜索里权重低，引流插件优先无 scope

## README（按下载量前 6 的插件拆解）
1. 首屏一张图 + 一句定位
2. 安装给 3 种：市场 / CLI / GitHub 子目录，并写更新卸载
3. 功能配截图或 GIF，不堆形容词
4. 给真实输入输出，复制即可跑
5. 末尾固定：兼容、许可、反馈、相关项目
6. 10–80KB，长文反而下载高

## 工程约定
- engines.dsh 写 `>=0.2.0-rc.2`，不写上界（rc.3 已覆盖）
- output 必须带 schema + render，参数 required 放对象级数组
- 多工具插件用循环注册，避免复制粘贴
- 本地先用 node --check + plugin_check，再提沙箱
